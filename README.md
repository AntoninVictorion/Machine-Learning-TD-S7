# Machine-Learning-TD-S7

This repository contains practical laboratory assignments and implementations of foundational Machine Learning algorithms in Python.

---

## 📂 Repository Structure

* **`LAB_1_Linear_Regression`**[cite: 2]: Simple and multiple linear regression, gradient descent, error metrics (MSE, RMSE, $R^2$).
* **`LAB_2_logistic_regression_KNN`**[cite: 2]: Supervised classification algorithms — binary/multiclass logistic regression and $k$-Nearest Neighbors ($k$-NN), evaluation metrics (confusion matrix, precision, recall, F1-score).
* **`LAB_3_Decision_Tree_and_Random_Forest`**[cite: 2]: Decision trees (Gini impurity / entropy) and ensemble methods (Random Forest, bagging, feature importance).

---

## 🛠️ Tech Stack

* **Language:** Python 3
* **Core Libraries:**
  * `numpy` & `pandas`: Data manipulation and feature preprocessing
  * `matplotlib` & `seaborn`: Exploratory data analysis and visualization
  * `scikit-learn`: Model training, hyperparameter tuning, and evaluation
